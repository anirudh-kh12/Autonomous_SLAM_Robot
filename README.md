# Autonomous SLAM Mobile Robot

A low-cost autonomous indoor mobile robot designed to map its environment, estimate its position, navigate to destinations and respond to obstacles.

## Project Goals

- Develop a SLAM-based mobile robot.
- Simulate and validate navigation algorithms before physical implementation.
- Build a custom 3D-printed chassis.
- Implement autonomous navigation and obstacle handling.
- Develop a browser-based dashboard for live monitoring and manual/autonomous control.
- Evaluate performance through repeatable experiments.

## Planned Technologies

- MATLAB — simulation and algorithm experiments
- Ubuntu Linux and ROS 2 — robotics software
- Python — backend and integration
- HTML, CSS and JavaScript — web dashboard
- ESP32 or Arduino — low-level control
- 2D LiDAR and wheel encoders — mapping and odometry
- Mechanical CAD software — chassis design
- Git and GitHub — version control

Technology and hardware selections are subject to compatibility testing.

## Current Status

Planning and environment setup. Required MATLAB robotics products are being installed and verified.

## Repository Structure

- `docs/` — architecture, research and project documentation
- `simulation/` — MATLAB and ROS 2 experiments
- `hardware/` — firmware, CAD and wiring
- `software/backend/` — backend services
- `software/frontend/` — web dashboard
- `tests/` — validation and test results
- `media/` — project photos and demonstrations

## Development Philosophy

Simulation first, incremental hardware integration, safe testing, measured performance and documented design decisions.

This is a long-term personal engineering project intended for learning, portfolio development, hackathons and potential future academic project work.
